# Codex Safety Rules

- Do not use destructive Git commands unless the user explicitly requests them.
- Do not modify global Codex configuration unless the user explicitly asks.
- Do not overwrite user-authored plan content without reading it first.
- Do not infer completed alignment from an unanswered questionnaire; use recommended defaults and record that fact.
- Do not move a plan to `plans/done/` until selected phases are complete and smoke-test guidance exists.
